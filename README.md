- DR => Domain Rating => jitni hamein backlink miley hein aur jitni website sey miley hein un sab ki mila k jo authority banti hae => jitni acha DA means achi sites sey backlinks aa rhy => jitni kam means low quality website sey links aa rhy

- Refering Domain => Hamari website kitni websites pey mention hae

## Anchor Text Types:

- Main Keyword: Main Niche => Home page pey jo keyword target kiya (e.g Mcdonald's Menu)
- Related Keyword/ Long tail keywords: Main Niche k elawa keyword (e.g Mcdonald's Drink Menu)
- Generic Anchors: (General World Related to niche) => (e.g PcsArt Mod APK => android app, latest version, free download, editing app)
- Direct Url => Url hi anchor ho  e.g imagepromptlab.com
